# Cartão de votação (pergunta ao dono)

Uma pergunta por vez, só depois de tentar resolver sozinho. O dono responde sem abrir nada.

| Campo | Conteúdo |
|---|---|
| **O que se pede** | {{Uma frase: aprovar, escolher ou recusar o quê}} |
| **Antes / depois** | {{prints lado a lado, mesmo aparelho e estado; ou "não existia"}} |
| **O que mudou** | {{uma linha}} |
| **Por quê** | {{o dado ou o erro que motivou}} |
| **Se aprovar** | {{o que acontece em seguida}} |
| **Link da ação** | {{o link pronto; sem ele, não é "esperando você"}} |
