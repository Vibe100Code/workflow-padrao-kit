# spec-kit

Desenvolvimento guiado por especificação: a feature grande nasce como spec, vira plano e tarefas, e só então código.

| | |
|---|---|
| Instalar no projeto | `scripts/instalar-projeto.sh <repo> --skills spec` (copia as 11 skills `speckit-*` e a estrutura `.specify/`) |
| Ordem | `speckit-specify` → `speckit-clarify` → `speckit-plan` → `speckit-tasks` → `speckit-analyze` → `speckit-implement` → `speckit-converge` |
| Apoio | `speckit-checklist`, `speckit-constitution`, `speckit-agent-context-update`, `speckit-taskstoissues` |
| Origem | [github/spec-kit](https://github.com/github/spec-kit) · MIT |
