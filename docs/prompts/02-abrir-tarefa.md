# Abrir uma tarefa

**Quando usar:** Toda frente que edita arquivo.

```
Tarefa: {{o que mudar, em uma frase}}.
Abra uma sessão própria (node scripts/nova-sessao.mjs {{tipo}}/{{nome}}) e, antes de editar,
responda por escrito: (1) evidência do problema, (2) o que a mudança alcança, (3) risco,
(4) como você vai provar que ficou certo. Não edite nada antes das quatro respostas.
```

**O que esperar:** Worktree aberta e as quatro respostas com evidência (arquivo:linha, saída de comando).
