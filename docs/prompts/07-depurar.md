# Depurar um erro

**Quando usar:** Erro, teste vermelho ou comportamento estranho.

```
Use superpowers:systematic-debugging. Reproduza o erro primeiro e cole a reprodução.
Isole a causa com evidência (arquivo:linha) antes de propor qualquer correção. Se a causa
for pré-condição faltando ou outra sessão mexendo no mesmo lugar, diga isso em vez de
"consertar".
```

**O que esperar:** Reprodução, causa com evidência e só então a correção mínima, com teste que pegaria a volta do erro.
