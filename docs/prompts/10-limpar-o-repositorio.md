# Limpar o repositório

**Quando usar:** Código morto, TODO velho, dependência sem uso, worktrees acumuladas.

```
Rode a skill sanear: meça antes de apagar (quem usa, desde quando, evidência). Liste o
que sairia com a prova de que não é usado e espere meu OK antes de remover. Depois rode
node scripts/sessoes-encerradas.mjs para ver as worktrees já integradas.
```

**O que esperar:** Inventário com evidência; nada é apagado sem OK.
