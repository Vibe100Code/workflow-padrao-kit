# Começar um projeto

**Quando usar:** Projeto novo, ou `BRIEFING.md` vazio ou cheio de `a confirmar`.

```
Vamos começar o projeto. Rode a skill iniciar-projeto: faça o questionário em blocos,
procure antes nos arquivos o que já está escrito (e cite a fonte), grave cada bloco no
BRIEFING.md na hora e marque `a confirmar` no que eu não souber. No fim, mostre um resumo
de 5 a 8 linhas e só as pendências que bloqueiam algo.
```

**O que esperar:** `BRIEFING.md` preenchido, `papeis` no `workflow.config.json`, lista curta de pendências.
