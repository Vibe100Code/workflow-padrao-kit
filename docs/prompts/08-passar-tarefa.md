# Passar ou retomar uma tarefa

**Quando usar:** Sessão vai acabar, ou outra sessão vai continuar.

```
Escreva a passagem com docs/PASSAGEM-DE-TAREFA.md: estado real (git status, commits à
frente da base, processos vivos), o que foi provado, o que falta e o próximo passo exato.
Nada de "quase pronto": ou está provado, ou está listado como pendente.
```

**O que esperar:** Uma passagem que outra sessão retoma sem perguntar nada.
