# Registrar o que se aprendeu

**Quando usar:** Problema não trivial resolvido, ou erro que se repetiu.

```
Rode a skill extract-approach e grave learnings/{{AAAA-MM-DD}}-{{slug}}.md: o problema,
o que não funcionou, o que funcionou e como reconhecer da próxima vez. Se o mesmo erro já
aconteceu duas vezes, proponha uma regra em regras/ (com data e incidente) ou um hook.
```

**O que esperar:** Nota em `learnings/`; regra ou hook novo quando o erro é recorrente.
