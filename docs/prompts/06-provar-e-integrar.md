# Provar e integrar

**Quando usar:** Revisão aprovada, críticos e altos corrigidos.

```
Prove pelo caminho do usuário: abra do zero, passe por todas as entradas que levam ao
estado alterado e confira a tela (ou a saída) inteira. Cole a prova. Depois rode
node scripts/integrar.mjs e, se passar, node scripts/tarefa.mjs concluir.
```

**O que esperar:** Prova colada (print ou log), integração pela fila, tarefa marcada como concluída.
