# Origem das regras

Cada regra de `templates/projeto/regras/` veio de uma regra do fluxo de origem, generalizada. O que era específico do produto de origem (nomes de telas, tokens de design, servidores, máquinas e pessoas) ficou de fora e virou termo genérico.

| Regra do kit | Veio de |
|---|---|
| `002-analise-antes-de-alterar.md` | análise antes de alterar |
| `003-continuidade-e-passagem-de-tarefa.md`, `004-saida-comprimida-nao-prova-ausencia.md` | continuidade de execução |
| `005-entrada-minima.md`, `006-hierarquia-e-isolamento-de-sessoes.md` | estrutura de trabalho e regras globais |
| `007-regra-se-le-pelo-porque.md` | regras globais |
| `008-ondas-paralelas-de-implementacao.md` | ondas paralelas |
| `009-onda-de-investigacao-em-arquivo-unico.md` | onda de investigação |
| `010-prova-pelo-caminho-do-usuario.md` | prova pelo caminho do usuário |
| `011-revisao-independente-somente-leitura.md` | revisores externos, estrutura de trabalho |
| `012-roteamento-de-especialistas-e-camada-de-modelo.md` | roteamento de especialistas |
| `013-design-system-obrigatorio-e-divida-decrescente.md` | design system obrigatório |
